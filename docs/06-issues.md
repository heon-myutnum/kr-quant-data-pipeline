# 6. 작업 목록과 설계 게이트

`docs/06-issues.md`. 인원이 미정이라 2인 기준으로 분담했습니다. 1인이면 번호 순서대로 진행합니다. **A**: 인프라, DB / **B**: 수집, API

## 먼저 할 일

KRX는 인증키 발급 후 API별 승인이 필요합니다. 승인이 늦으면 v0.1.0 전체가 밀리므로 **오늘 신청**합니다.

## 설계 게이트

게이트는 설계 전제를 코드 전에 판정합니다. 결과는 `docs/gate-results.md`에 기록하고, 이후 프롬프트가 이 파일을 입력으로 씁니다. 원천 값은 적지 않고 판정, 건수, 필드 이름만 적습니다.
