# 8. 품질 규칙 카탈로그

`docs/08-data-quality.md`. 규칙은 `conf/dq_rules.yaml`로 관리하고 `meta.dq_rule`에 동기화합니다. 임계값은 초기값이며 실제 데이터 분포를 본 뒤 조정합니다.

| 심각도 | 동작 |
|---|---|
| `warn` | 기록하고 진행 |
| `quarantine` | 위반 행을 `meta.quarantine_row`로 옮기고 나머지 진행. 대상일 격리 비율이 0.5%를 넘으면 빌드 차단 |
| `block` | 빌드 발행 차단. `meta.fn_publish_build`가 강제 |

오탐은 규칙을 끄지 않고 `meta.dq_exception`에 사유와 승인자를 남깁니다.

## 수집

| ID | 내용 | 임계값 | 심각도 |
|---|---|---|---|

| R-IN-02 | 성공 기록인데 본문이 오류이거나 필수 필드 없음 | 1건 | block |
| R-IN-03 | 소스 정정 감지 (`raw.v_revision`) | 1건 | warn |
| R-IN-04 | 하트비트 15분 초과 `running` | 1건 | warn |
| R-IN-05 | DART 최근 성공 후 18시간 초과 | | warn |

## 시세 유효성

| ID | 내용 | 임계값 | 심각도 |
|---|---|---|---|
| R-PX-01 | OHLC 제약 위반 (DDL CHECK와 동일 조건) | 행 단위 | quarantine |
| R-PX-02 | 평균 체결가(`거래대금/거래량`)가 고저 범위 밖 | ±1% | quarantine |
| R-PX-03 | `FLUC_RT`와 `종가/기준가-1` 불일치 | 0.02%p | warn |
| R-PX-04 | 시총과 `종가×상장주식수` 불일치 | 0.5% | warn |
| R-PX-05 | 코드 형식 위반 (`^[0-9A-Z]{6}$`) | 행 단위 | quarantine |
| R-PX-20 | `종가/기준가-1`의 절댓값이 그날 가격제한폭 초과 | 한도 +0.5%p | warn |
